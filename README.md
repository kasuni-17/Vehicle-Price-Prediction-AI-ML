# Vehicle Price Prediction 🚗💰

<img src="Vehicle Price Prediction .png" width="700">

A Machine Learning project developed to predict used vehicle prices using regression algorithms and data preprocessing techniques.

---

## 📌 Features

- Data Cleaning & Preprocessing
- Feature Engineering
- Multiple ML Models
- Model Comparison & Evaluation

---

## 🤖 Models Used

- Linear Regression
- Decision Tree Regressor
- Random Forest Regressor
- KNN Regression
- Support Vector Regression (SVR)

---

## 🛠️ Technologies

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib

---

## 📊 Best Result

✅ Random Forest Regressor achieved the highest accuracy with an R² score of approximately **0.84**

---

## 📂 Dataset

Vehicle Dataset from CarDekho (Kaggle)  
• Link to dataset: https://www.kaggle.com/datasets/nehalbirla/vehicle
dataset-fromcardekho

---

## 🚀 Purpose

To provide accurate and transparent vehicle price predictions using Machine Learning.
